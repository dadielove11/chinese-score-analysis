# 初中语文学情分析工具

一个面向初中语文教师的离线成绩分析工具。程序以“本地 exe + 本地网页”的形式运行：双击启动后在浏览器中导入成绩文件，完成班级统计、学生个人趋势分析、进退步概览和结果导出。

本项目不依赖 GPT 或云端模型，适合在普通 Windows 电脑上离线使用。

## 功能概览

- **统一导入入口**：首页只保留一个“导入成绩文件”入口，支持一次选择多个同类型 Excel 或成绩截图，减少教师判断成本。
- **Excel 批量导入**：支持多个 `.xlsx/.xlsm` 文件，自动识别姓名、语文成绩、班级位次、班级和考试名称，并提供可下载模板。
- **图片导入与校对**：支持成绩表截图导入，优先使用本地 OCR 识别，识别结果进入校对页后再确认入库。
- **多班级管理**：支持 7 班、8 班等不同班级分开查看，个人趋势和进退步概览均可按班级筛选。
- **考试顺序管理**：自动识别七上、七下、期中、期末、第一次月考等常见考试顺序，也支持手动调整考试顺序。
- **个人趋势图**：将学生多次语文成绩和班级位次合并到一张趋势图中，用不同颜色线条区分；支持保存当前学生 PNG 大图，支持批量导出本班所有学生趋势图。
- **进退步概览**：按学生展示每次考试成绩、相邻考试变化、总分变化和位次变化，并支持按姓名、分数、进步/退步、位次等方式排序。
- **班级统计**：按考试统计人数、均分、中位数、最高分、最低分、优秀率、良好率、及格率和低分率。
- **自定义分数线**：默认优秀 80、良好 70、及格 60、低分 40，可在页面中自行修改。
- **Excel 导出**：导出成绩明细、班级总览、进退步概览；进退步概览会按实际考试次数展开列。
- **数据管理**：支持按班级、考试、学生、班级+考试、班级+学生删除数据，也保留清空全部数据入口；删除和清空均有二次确认提示。

## 优势和特点

- **离线可用**：核心功能均在本地运行，不需要联网，不需要账号，不需要 API Key。
- **适合非技术用户**：最终可打包成一个文件夹，普通用户解压后双击 `StudentAnalysis.exe` 即可使用。
- **导入流程稳妥**：Excel 和图片导入后都会进入确认/校对页，班级、考试名称和考试顺序都能在写入前核对调整；删除和清空操作均有二次确认，防止误操作。
- **新用户引导**：尚无成绩数据时，首页自动显示三步入门说明，引导教师完成第一次导入。
- **适配真实成绩表**：支持多文件、多班级、多考试名称和缺失位次场景；没有位次时可按分数自动计算班级排名。
- **保护学生数据**：学生成绩默认保存在本机 `data/` 目录，不上传服务器；Git 仓库默认忽略 `data/` 和 `uploads/`。
- **便于分发**：提供 PyInstaller 打包脚本，可生成干净的离线压缩包和使用说明文档。

## 本地开发运行

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```

程序默认访问地址：

```text
http://127.0.0.1:8765
```

## 打包离线版

推荐直接运行：

```powershell
.\build_release.bat
```

脚本会完成三件事：

1. 关闭正在运行的旧版 `StudentAnalysis.exe`。
2. 根据 `StudentAnalysis.spec` 重新打包程序。
3. 生成可发给他人使用的离线压缩包：

```text
release\初中语文学情分析工具_离线版.zip
```

手动打包命令：

```powershell
pyinstaller -y StudentAnalysis.spec
python tools\create_release_package.py
```

## 隐私说明

仓库不应提交真实学生成绩、上传图片、导出的 Excel、打包产物或本地运行数据。`.gitignore` 已默认排除：

- `data/`
- `uploads/`
- `build/`
- `dist/`
- `release/`

## 适用场景

适合语文教师在阶段测验、期中、期末等考试后快速完成：

- 班级成绩概览
- 学生个人成绩与位次变化追踪
- 进步/退步学生筛选
- 可发送、可存档的 Excel 和 PNG 分析结果
